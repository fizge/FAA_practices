# 📌 Fundamentos de Machine Learning - Prácticas

Bienvenido al repositorio de las prácticas de la asignatura **Fundamentos de Machine Learning**. Aquí organizaremos y desarrollaremos los ejercicios siguiendo una estructura clara y colaborativa.

## 📂 Estructura del Repositorio

El repositorio está dividido en dos secciones principales:

1. **Código**: Contiene el desarrollo de las prácticas.
2. **Trabajo**: Organiza la distribución del trabajo de cada ejercicio.

### 🔹 Código

Estructura de carpetas para el desarrollo de las prácticas:

```
📁 src/
├── 📁 Boletin_X/
│   ├── 📄 entrega(dni).jl  # Archivo final para entregar
│   ├── 📁 Ejercicio_Y/
│   │   ├── 📄 .ipynb   # Desarrollo inicial y anotaciones
│   │   ├── 📄 .jl      # Implementación final en Julia
│   │   ├── 📄 test.jl  # Casos de prueba antes de la entrega
```

### 🔹 Trabajo

Aquí organizamos la asignación de tareas:

```
📁 Trabajo/
 ├── 📁 Boletin_X/
 │   ├── 📄 Ejercicio_Y/    # Documentación de la distribución del trabajo
```

## 🛠️ Flujo de Trabajo

1. Cada ejercicio comienza en un **notebook**, donde se describen brevemente los pasos y se desarrollan las soluciones.
2. Una vez completado, se transfiere a un archivo **.jl**.
3. Se ejecutan los **tests proporcionados por los profesores**.
4. Cuando una función esté **lista** añadir SIEMPRE al **archivo de entrega** de cada boletín. 
5. Si todos los tests pasan, el código está listo para ser entregado. En caso de correcciones, se actualiza y se vuelve a probar.

## 🔀 Colaboración con Git

### 📢 **Importante:**

✅ Cada miembro del equipo trabaja en su propia **rama** hasta completar el ejercicio.

✅ Una vez finalizado, se realiza un **Pull Request (PR)** para fusionar los cambios en la rama principal.

✅ Antes de fusionar, el código debe ser revisado y aprobado por otro miembro del equipo.

## 📝 Notas

* Siempre documenta brevemente lo que estás haciendo en el **notebook**.
* Asegúrate de que el código pase todos los **tests** antes de entregarlo.
* Mantén el repositorio organizado siguiendo la estructura definida.
